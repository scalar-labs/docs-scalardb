# 監視の概要

import TranslationBanner from '/src/components/_translation-ja-jp.mdx';
import DocCardList from "@theme/DocCardList";

<TranslationBanner />

監視は、ScalarDB デプロイメントの健全性とパフォーマンスを維持するために不可欠です。このセクションでは、Kubernetes クラスター環境での ScalarDB の監視に関するガイダンスを提供します。これにはシステムの可用性の確認、時系列メトリックの収集、および監視ダッシュボードを通じたログの表示が含まれます。
