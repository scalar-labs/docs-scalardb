# 試用ライセンスキーの設定方法

import TranslationBanner from '/src/components/_translation-ja-jp.mdx';

<TranslationBanner />

ScalarDB Enterprise Standard/Premium および ScalarDB Analytics 用の以下の試用ライセンスキーを使用できます。商用ライセンスキーをお持ちの場合は、[商用ライセンスキーの設定方法](./commercial.mdx)を参照してライセンスキーを設定してください。

ScalarDB Enterprise Standard/Premium または ScalarDB Analytics を実行するには、設定ファイルを作成し、試用ライセンスキーと証明書をファイルに追加する必要があります。設定ファイルには、使用している製品に基づいて以下の設定をコピーし、ファイルに貼り付けてください。

:::warning

- これらのライセンスキーは、非本番環境での評価目的にのみ有効です。
- 試用ライセンスは現状有姿で提供され、動作保証はありません。本ライセンスの使用により生じた損害について、当社は一切の責任を負いません。
- 試用ライセンスを使用する場合、ライセンスの検証と有効期限の確認のために、ScalarDB Cluster および ScalarDB Analytics をインターネットに接続する必要があります。
- ライセンスキーの再配布やリバースエンジニアリングは固く禁じます。
- 試用ライセンスキーは定期的に更新されます。本番環境での使用については、[お問い合わせ](https://www.scalar-labs.com/contact)から商用ライセンスを取得してください。

:::

:::note

ScalarDB Core は、[GitHub](https://github.com/scalar-labs/scalardb) で Apache 2.0 ライセンスの下でオープンソースソフトウェアとして利用可能です。

:::
