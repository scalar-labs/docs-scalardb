Before you deploy ScalarDB Cluster in an OpenShift cluster, you need to install the following tools:

1. Install the `oc` command by following the [official OpenShift documentation](https://docs.redhat.com/en/documentation/openshift_container_platform/4.21/html/cli_tools/openshift-cli-oc). You should use the same version of `oc` as the supported version of OpenShift you will use. For details about compatibility, see **Table 2.1. Compatibility Matrix** in [2.3.1. The oc binary](https://docs.redhat.com/en/documentation/openshift_container_platform/4.21/html/cli_tools/openshift-cli-oc#the-oc-binary). You can also see the OpenShift version that ScalarDB Cluster supports on the [Requirements](../requirements#kubernetes) page.
1. Install the `helm` command by following the [official Helm documentation](https://helm.sh/docs/intro/install/).
