Before you deploy ScalarDB Cluster in a Kubernetes cluster, you need to install the following tools:

1. Install the `kubectl` command by following the [official Kubernetes documentation](https://kubernetes.io/docs/tasks/tools/#kubectl). You should use the same version of `kubectl` as the supported version of Kubernetes you will use. You can see the supported Kubernetes version on the [Requirements](../requirements#kubernetes) page.
1. Install the `helm` command by following the [official Helm documentation](https://helm.sh/docs/intro/install/).
