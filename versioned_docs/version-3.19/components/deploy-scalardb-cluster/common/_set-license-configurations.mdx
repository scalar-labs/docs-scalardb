You must set the license configurations, replacing the contents in the angle brackets as described, based on the license you have. For details about license configurations, see [How to Configure a License Key](../scalar-licensing).

```yaml
scalardbCluster:
  scalardbClusterNodeProperties: |
    scalar.db.cluster.node.licensing.license_key=<YOUR_LICENSE_KEY>
    scalar.db.cluster.node.licensing.license_check_cert_pem=<CERTIFICATE>
```
