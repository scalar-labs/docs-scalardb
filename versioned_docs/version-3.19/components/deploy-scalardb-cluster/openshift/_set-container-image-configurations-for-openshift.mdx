Set the container image configuration to `scalardbCluster.image.repository`. For OpenShift, only ScalarDB Cluster Enterprise Premium is available.

<CodeBlock language="yaml">
{`scalardbCluster:
  image:
    repository: "registry.connect.redhat.com/scalar-labs/scalardb-cluster-node-ubi-byol-premium"`}
</CodeBlock>
