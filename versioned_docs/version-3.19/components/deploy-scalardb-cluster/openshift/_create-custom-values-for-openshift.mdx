Create your custom values file `scalardb-cluster.yaml` based on your environment and your decisions in the previous steps.

<h4>Set the required configurations</h4>

1. Set the container image configurations.

    <SetContainerImageConfigurationsForOpenShift />

1. Set the membership configurations.

    <SetMembershipConfigurations />

1. Set the license configurations.

    <SetLicenseConfigurations />

1. Set the database configurations.

    Based on the backend databases you chose in **Deploy a backend database**, set the database configurations in `scalardbCluster.scalardbClusterNodeProperties`. Select one of the following databases to see an example of these configurations. Also, please replace the contents in the angle brackets as described.

    <SetDatabaseConfigurations />

    :::note

    In a later step, you will need to create a Kubernetes secret and set the configuration `scalardbCluster.secretName`.

    :::

1. Set the service configurations.

    <SetServiceConfigurations k8sDistroName="OpenShift" />

1. Set the secret name configurations.

    <SetSecretNameConfigurations />
